## Scope and mode

`/presenter` is an Operate surface for the managed GitHub Factory demo.

## Audience and job

A technical presenter uses it while an external audience watches. The presenter
must know what is happening, which authority acts next, where to perform the
human decision, and whether the run settled cleanly.

## Task and content

The primary task is launch one reviewed scenario, follow its six stages, perform
manual GitHub and Cloud actions, then reset only terminal evidence. Controller
SQLite is authoritative. GitHub Project and Cloud Activity remain linked
projections. The page must expose dependencies, attempts, artifacts, exact
identities, deployment, and retained failure without credentials.

## Direction and memorable moment

Extend Barista's porcelain/espresso operator world as a presenter rundown. A
large current-stage sentence and dark next-action field make the current
authority boundary unmistakable; the six-stage rail and dependency workbench
show why the workflow advances.

## Constraints

Public reads are credential-free and no-store. Launch/reset require a separate
manually entered presenter token held in session storage. Reset cannot claim
unsupported cancellation. Responsive, keyboard accessible, reduced-motion
safe, no external page resources.
